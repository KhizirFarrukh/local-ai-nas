### E007 | 06:59 | VERIFICATION (execution step 3; web sources checked 2026-09-28)
- **mdadm** (man page, man7.org `mdadm(8)`): **verified**
  - supports LINEAR, RAID0, RAID1, **RAID4**, RAID5, RAID6, and RAID10;
  - `--grow` changes device count and size for "Linear and RAID levels 0/1/4/5/6", and the level "between 0, 1, 5, and 6" (and 0 ↔ 10);
  - a write-intent bitmap (`--bitmap=internal`);
  - `--write-journal` "for the RAID-4/5/6 array" (an SSD journal against the write hole).
  - **Nesting** (an md array as a member of another, as in the user's example): **partly verified**.
    - The man page does not document it. It works in practice (`mdadm --create /dev/md1 -l5 /dev/md0 /dev/sde /dev/sdf`, Arch Linux forum thread 111657).
    - The same report shows the inner array missing from the outer one after a reboot, an assembly-order problem.
    - Design consequence: the storage helper controls assembly order (inner arrays first), and S13's loop-device tests include reboot and re-assembly.
  - License: GPL (separate host program).
- **goimagehash** (github.com/corona10/goimagehash; pkg.go.dev): BSD-2-Clause; pure Go; average, difference, and perception hashes plus extended variants; `Distance()` (Hamming).
  - **Maintenance concern:** the last release is v1.1.0 (2022-05-26), over four years ago.
  - The perceptual-hash ADR therefore compares it with a small in-house dHash/pHash (a DCT on 32×32 pixels, about a hundred lines, no dependency).
- **libvips + ExifTool metadata preservation:** verified.
  - libvips savers take `keep` flags (none, exif, xmp, iptc, icc, other, gainmap, all).
  - `thumbnail` interprets orientation to make images upright. `autorot` "removes the orientation tag … to prevent accidental double rotation", so the consistent rule is: **rotate the pixels, reset the tag**.
  - ExifTool 13.59 (2026-05-27) writes JPEG, PNG, WebP, HEIC/HEIF, AVIF, TIFF, GIF, DNG/CR2/NEF/ARW, MP4, MOV, and M4A. The copy command is `exiftool -tagsfromfile SRC -all:all DST`; ICC needs `-icc_profile` named explicitly, and "unsafe" tags need `-unsafe`.
  - HEIC output needs an HEVC encoder in libheif: x265 (GPL-2.0-or-later) or kvazaar (BSD-3-Clause).
- **FFmpeg encoder licensing** (ffmpeg.org/legal.html): verified.
  - FFmpeg is LGPL-2.1-or-later, "however … if those parts [GPL] get used the GPL applies to all of FFmpeg"; libx264 is named as GPL.
  - libx265: GPL-2.0-or-later. AV1: libaom BSD-2-Clause + AOMedia Patent License 1.0; SVT-AV1 BSD-3-Clause-Clear (since v0.9) + AOMedia Patent License 1.0.
