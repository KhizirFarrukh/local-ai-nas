# docs

Project documentation for users and developers.

- `licensing.md`: dependency license policy (S01.1-T02).
- `testing.md`: how tests, fuzzing, coverage, and lint are run (S01.1-T04).
- `api/errors.md`: the error format (RFC 9457 problem details) and the codes so far (S01.1); the full catalogue comes in S01.5.
- `api/conventions.md`: the rules every endpoint follows, with the review checklist (S01.5-T01).
- `api/versioning.md`: versioning and deprecation policy (S01.5-T02).
- `perf/`: performance baselines (S01.7).
- Install, admin, and user guides follow in S11.4.

The agent's working documents (plan, rules, stage documents, logs) live in [`code-agent-docs/`](../code-agent-docs/).
