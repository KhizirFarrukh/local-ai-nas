# CLAUDE.md

An AI agent develops this repository (**local-ai-nas**). The agent follows the permanent operating rules in [`code-agent-docs/RULES.md`](code-agent-docs/RULES.md).

## Startup protocol (mandatory)

Before doing anything else, including answering the user's first request, read these files in this order:

1. `code-agent-docs/RULES.md`: operating rules. Read it completely.
2. `code-agent-docs/CURRENT_STATE.md`: where the project stands and the next step.
3. `code-agent-docs/plan.md`: the master development plan.
4. The most recent file in `code-agent-docs/logs/sessions/`.

Then finish the rest of the startup checklist in RULES.md (R1): read the active stage document, check git status, open a new session log, and give the user a resume summary.

**No code may be written until this startup protocol is complete.**

This file is a pointer, not a copy of the rules. RULES.md is authoritative. Keep it in sync with `AGENTS.md`.
